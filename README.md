# Basic CI/CD - Задание

1. **Настройка gitlab-runner**
   - Поднять виртуальную машину *Ubuntu Server 22.04 LTS*.
   - Установить и запустить **gitlab-runner**.
   - Зарегистрировать **gitlab-runner** для проекта DO6_CICD.

2. **Сборка (CI)**
   - Настроить этап сборки приложения из проекта *SimpleBashUtils* или из папки code-samples.
   - Добавить сборку через Makefile в файл `.gitlab-ci.yml`.
   - Сохранить артефакты сборки с хранением 30 дней.

3. **Тест кодстайла (CI)**
   - Написать этап для запуска *clang-format*.
   - Фейлить пайплайн при несоответствии кодстайлу.
   - Вывести результат работы *clang-format* в пайплайн.

4. **Интеграционные тесты (CI)**
   - Настроить этап для запуска интеграционных тестов.
   - Для *SimpleBashUtils* использовать уже написанные тесты, для code-samples создать самостоятельно.
   - Запускать этап только при успешной сборке и тесте кодстайла.
   - Фейлить пайплайн при провале тестов.
   - Выводить результат тестов в пайплайн.

5. **Этап деплоя (CD)**
   - Поднять вторую виртуальную машину *Ubuntu Server 22.04 LTS* (prod).
   - Написать этап CD для развёртывания артефактов на второй сервер.
   - Создать bash-скрипт для копирования файлов через **ssh**/**scp** в `/usr/local/bin`.
   - Добавить этап деплоя в `.gitlab-ci.yml`.
   - Запускать деплой вручную после успешного прохождения всех CI этапов.
   - Сохранить дампы образов виртуальных машин (не в git).

6. **Дополнительно: уведомления**
   - Настроить уведомления о статусе пайплайна в Telegram через бота «[твой nickname] DO6 CI/CD».
   - Уведомления должны показывать успешность этапов CI и CD.
   - Текст уведомления может быть произвольным.
